# U++ / Ui skills

This folder contains distribution copies of the skills maintained in [upp_Ui/skills](https://github.com/Trilec/upp_Ui/tree/main/skills).

- [upp-ui-development.zip](upp-ui-development.zip): native U++ coding, ownership, controls, layouts, models, styling and builds.
- [upp-ui-html-mockup.zip](upp-ui-html-mockup.zip): HTML/CSS/JS prototypes grounded in native Ui capabilities.

Import each ZIP separately. All instructions and supporting references are included. The matching subfolders contain the unpacked skills; there are no additional files to upload alongside a ZIP.

See the [repository overview](../README.md) for usage and examples. Maintenance and packaging scripts live in the upp_Ui repository, where the source skills are updated before these distribution copies are refreshed.
